Integrations

LMS & Google Workspace

Learning Management Systems

Moodle — Web Services API

Auto-pulls courses, assignments, student roster, grades, submissions, page content, and PDF materials. Writes grades back via mod_assign_save_grade. Posts announcements via forum module.

Canvas — REST API

Pulls syllabus, assignments, rubrics, modules, roster, submissions, discussions, quizzes. Writes grades & feedback. Posts announcements as discussion topics.

LTI 1.3 — Launch Protocol

Standardized single sign-on for both Canvas and Moodle. JWT validation, role mapping (student/instructor/TA), automatic course discovery and enrollment sync. Multi-tenant.

Google Workspace (OAuth 2.0)

Google Calendar

Free/busy availability lookup, create events with attendees, cancel events. Powers the meeting scheduling when the agent detects a struggling student.

Google Sheets

Create spreadsheets with data, read from URLs or IDs, list Docere-created sheets. Powers the gradebook sync — import grades, validate, auto-fix errors, push back to LMS.

Google Docs

Create rich-text documents on demand. Used by the agent to generate study guides, notes, and reports for instructors.

Gmail

Send HTML emails with CC/BCC. Agent can draft and send emails to students or groups — e.g., reminders, meeting confirmations, progress updates.

Integrations

AI & Infrastructure

Claude — Anthropic

Primary LLM for tutoring, grading, strategy selection, and verification. Models: claude-sonnet-4-20250514, claude-opus. Streaming responses with circuit breaker and retry logic.

GPT-4o — OpenAI

Fallback LLM provider. Chat completions with streaming. Used when Claude is unavailable or for specific tasks requiring a second model perspective.

Voyage AI — Embeddings

Primary embedding provider (voyage-3, 1024-dim). Batch support with LRU cache (1000 entries, ~50% cost reduction). Powers semantic search across student memory and course materials.

Qdrant — Vector DB

Vector storage for all semantic memory. Cosine similarity search with score thresholds. Stores student interactions, course materials, concept embeddings. Circuit breaker on failures.

PostgreSQL — Primary DB

Relational database for users, courses, enrollments, assignments, grades, profiles, memory records, tokens, and flashcards. Async driver via asyncpg.

Redis — Cache

Session caching, rate limiting, and temporary data storage. Powers the middleware that protects API endpoints from abuse.
