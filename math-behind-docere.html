Step 1 — Memory Retrieval

Cosine similarity over dense embeddings

When a student sends a message, we retrieve relevant context from three sources in parallel.

sim(q, d) = q · d / (‖q‖ × ‖d‖)
  • Query — student's message embedded to 1024-dim vector (Voyage AI)
  • Corpus — course materials, past interactions, conversation summaries
  • Threshold — score ≥ 0.15 to catch vague follow-ups
  • Budget — 4000 token cap, teacher context gets priority

Why cosine over euclidean?

Embedding magnitude varies by content length. Cosine normalizes this — two texts about "derivatives" will be close regardless of whether one is a sentence and the other a paragraph. Qdrant handles this in HNSW index space.

Step 2 — Strategy Selection

Contextual UCB1 multi-armed bandit

Each teaching strategy is an "arm." We pick the one with the highest upper confidence bound.

UCB1(s) = x̄(s) + c · √( ln(N) / n(s) )
x̄(s) — avg score for strategy s
N — total selections across all strategies
n(s) — times strategy s has been used
c = √2 — exploration constant

The explore/exploit tradeoff:

  • High x̄ — strategy has performed well (exploit)
  • Low n(s) — strategy is undertested, √ term is large (explore)
  • Untested strategies → n(s) = 0 → score = ∞ (always tried first)

Why contextual?

Global UCB1 learns one ranking for all students. But Socratic works great for confused beginners and poorly for experienced students. We bucket by confusion × experience × quality = 27 contexts, each with its own UCB1 stats. Falls back to global when a bucket has < 3 observations.

Step 3 — Interaction Scoring

Hybrid scoring — 70% LLM judge + 30% heuristics

After each exchange, we measure how effective the tutoring response was. This is the signal that drives everything.

S = 0.7 × Sllm + 0.3 × Sheuristic

LLM-as-judge (4 dimensions):

Helpfulness35%Did it move the student forward?
Clarity25%Was it easy to understand?
Understanding Δ25%Did confusion decrease?
Engagement15%Did the student stay engaged?
Sllm = 0.35h + 0.25c + 0.25Δu + 0.15e

Heuristic signals

Response time — fast followup suggests engagement

Question presence — student asking deeper questions = good sign

Message length — very short replies may signal disengagement

Followup type — classified as deeper_question, still_confused, moved_on, or disengaged

Step 4 — Statistical Tracking

Online statistics — no batch recomputation needed

Every metric updates incrementally as new scores arrive. No nightly jobs, no full table scans.

Running average (Welford-style):

x̄n = (x̄n-1 × (n-1) + xnew) / n

Success rate (binary threshold):

rn = (rn-1 × (n-1) + Ι[score ≥ 0.6]) / n

Ι[·] is the indicator function — 1 if the score meets the threshold, 0 otherwise.

Grade signal blending:

Sblended = 0.7 × Scomposite + 0.3 × G%

When an LMS grade arrives, it's blended into the original interaction score. The delta propagates to the parent strategy's avg_score.

Wilson Score Interval

Confidence interval for success rate. Better than normal approximation for small n — handles edge cases (p=0, p=1) gracefully.

CI = z × √( p(1-p)/n + z²/4n² ) / (1 + z²/n)

z = 1.96 for 95% confidence. At n=5 with p=0.6, CI ≈ ±0.35. At n=100, CI ≈ ±0.08. More data = tighter bounds = more confident pruning decisions.

Why Wilson over Normal?

Normal CI can produce intervals below 0 or above 1 for small samples. Wilson is always bounded in [0, 1]. Critical when we only have 5-10 observations per strategy-context bucket.

Pruning rule:

prune if n ≥ 20 AND x̄ < 0.3

Baseline strategies (the original 5 seeds) are immune — they're always available as fallbacks.

Mutation guard (convergence check):

J(A, B) = |WA ∩ WB| / max(|WA|, |WB|)

Reject mutation if word-level overlap > 80% with any active strategy. Prevents the archive from collapsing to near-duplicates.

Mutation with dimension feedback

The LLM mutator receives per-dimension score breakdowns for the parent strategy's best and worst interactions:

Topic: derivatives Helpfulness: 0.95 Clarity: 0.70 ← weak Engagement: 0.85 Composite: 0.85

The prompt instructs Claude to specifically improve the weakest dimensions while preserving strengths.

Putting It Together

The closed-loop learning system

Per-interaction (real-time):

  • Cosine similarity retrieves relevant memory
  • UCB1 selects strategy for this student context
  • LLM generates response using strategy + context
  • Hybrid scorer rates the interaction (4 dimensions)
  • Running avg + Wilson CI update immediately

Per-grade (every 2 hours):

  • LMS grades are fetched and linked to interactions from the past 14 days
  • Score blend: 70% composite + 30% grade percentage
  • Delta propagates back to strategy avg_score

Per-week (evolution):

  • Top K strategies mutated into variants
  • Convergence check prevents archive collapse
  • Weak strategies pruned, baselines protected
  • New variants enter the bandit pool at n=0 (→ UCB1 = ∞, guaranteed exploration)

Why this works

The key insight: new mutations automatically get explored first (UCB1 = ∞ when n=0). If they're good, they accumulate high scores and get exploited. If they're bad, they hit the prune threshold at n=20. The system can't get stuck — it always explores.
