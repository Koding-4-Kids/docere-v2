The Product

An AI tutor that lives inside the classroom

  • Plugs into Moodle/Canvas via LTI 1.3 — zero teacher setup
  • Auto-pulls syllabus, assignments, materials, grades
  • Remembers every student individually across sessions
  • Gets better at teaching over time
  • Schedules meetings when students need human help

Why this matters

Every other AI tutor is a standalone tool. Students have to paste their assignment in, explain the context, start from scratch each time. Docere already knows what they're working on, what they've struggled with, and what teaching approach works for them.

Algorithm Deep Dive

Memory Layer — RAG with student context

Three memory sources retrieved in parallel:

  • Teacher context — course materials embedded in Qdrant. Syllabus, assignments, lecture notes. Large docs get compressed via synthetic Q&A distillation (CARTRIDGES-inspired).
  • Student memory — past interactions, confusion events, breakthroughs. Semantic search to find relevant history for the current query.
  • Student profile — running aggregates: avg confusion score, engagement level, concept mastery map, interaction count.

Embedding Pipeline

Voyage AI embeddings (1024-dim) → Qdrant vector DB with cosine similarity search. Score threshold 0.15 to catch vague follow-up queries. Results deduplicated by point ID, not title.

Token Budget

Memory context is capped at 4000 tokens. Teacher context gets priority, then recent interactions, then older compressed summaries. Stale conversations auto-summarize after 50 messages.

Algorithm Deep Dive

Strategy Selection — UCB1 Multi-Armed Bandit

We don't hardcode one teaching style. The system learns which strategy works best for each student context.

UCB1(s) = x̄(s) + c × √(ln(N) / n(s))

How it works:

  • Context key — students are bucketed by confusion level (low/mid/high), experience (new/experienced), and interaction quality (poor/fair/good)
  • Exploration vs exploitation — UCB1 balances trying new strategies against using what's worked before
  • Strategy pruning — after 20+ uses, strategies scoring below 0.3 get removed. Top performers get evolved into new variants.

Current Strategies

Socratic — asks guiding questions, never gives answers directly

Error-Focused — identifies misconceptions and addresses them head-on

Scaffolding — breaks problems into small steps, gradually reduces support

Analogy-Based — explains concepts through real-world comparisons

Algorithm Deep Dive

Process Verification — closing the feedback loop

After each exchange, we score how effective it was. This is what makes the self-improvement loop possible.

Hybrid Scoring (70% LLM + 30% Heuristics)

LLM-as-judge — Claude evaluates the interaction on four dimensions, looking at what the student said next as signal.

Heuristics — response time (fast followup = engaged), question presence, message length, sentiment shift.

Four scoring dimensions:

  • Helpfulness (35%) — did the response move the student forward?
  • Clarity (25%) — was it easy to understand?
  • Understanding Δ (25%) — did confusion go down?
  • Engagement (15%) — did the student stay engaged?

Scores feed back into UCB1 bandit → strategies that produce higher scores get selected more often → system improves.
